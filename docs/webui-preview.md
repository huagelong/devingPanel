# HTML 页面原型与设计文档映射

日期：2026-10-24

本次产物位于 `webui/`，用于核对现有需求与页面设计，不替代 M1 技术选型或 M2 桌面客户端实现。需求中的真实 SSH、Docker、SQLite、系统凭据管理器与资源采样尚未实现。

## 视觉约定

- 全部页面复用同一 App Shell、表格、卡片、表单、按钮、Badge、Dialog、Sheet 和内联 SVG 图标函数。
- 颜色使用 `00-overview.md` 的 HSL CSS 变量，状态色只用于表达语义；图标统一 24px viewBox、18px 展示尺寸和描边。
- 桌面侧栏 224px，顶栏 56px，内容最大宽度 1280px，水平/垂直内边距 32px/24px。
- 窄屏侧栏切换为菜单，内容水平内边距 16px；宽表格仅在区块内滚动，发布配置自动换行。
- 页面及区块标题、正文、辅助文案、等宽日志和镜像名遵循设计总览的字号和字体约定。

2026-10-24 补充：设置增加本地配置 JSON 导入/导出与 S3 备份页面，详见 `docs/design/06-settings.md` 第 5 节。JSON 文件交互真实可用，S3 检查/记录仅为本地模拟，无云端请求；备份不包含凭据、变量值、镜像、卷或发布回滚材料。

## 验收方式

运行与测试命令见 `webui/README.md`。浏览器自动测试覆盖主要路由、主题、移动布局和关键状态交互，并生成截图供人工核对。演示数据的成功结果不代表真实 VPS 验证通过。

尚需桌面端实现的接口明确保留为提示，不用浏览器假存储代替安全存储；没有新增常驻 VPS 服务，也没有修改现有需求范围。
