# P2 主机列表 / 主机详情 设计文档

> 需求映射：H-1 添加编辑删除、H-2 连接测试、H-3 主机分组、H-4 凭据加密、S-1/S-2 资源监控

## 1. 页面目的

管理 VPS 连接配置；查看单台主机详情与实时资源监控；作为容器管理的入口。

## 2. 入口

- 侧边栏"主机"；Dashboard 主机卡片点击进入详情。

---

## 3. 主机列表页

### 3.1 布局

```
内容区
|
|-- 页头: "主机" + [添加主机] (variant=default)
|
|-- 分组筛选条 (如有分组): Tabs 或 Select: 全部 | myapp-prod | ...
|
|-- Table (Card 包裹)
|  列: 状态 | 别名 | 地址 | 用户 | 分组 | 容器数 | 最近连接 | 操作
|       ●在线  web-1   1.2.3.4  root  prod   5       2min前   [测试][...]
|  操作列: [测试连接] 图标按钮 + DropdownMenu(详情/编辑/删除)
```

### 3.2 添加 / 编辑主机 Dialog（sm:max-w-lg）

表单字段：

| 字段 | 控件 | 校验 |
|------|------|------|
| 别名 | Input | 必填 |
| 地址 | Input (mono) | 必填，IP 或域名 |
| SSH 端口 | Input number | 默认 22 |
| 用户名 | Input | 默认 root |
| 认证方式 | RadioGroup: 密码 / 私钥 | 必选 |
| 密码 / 私钥 | Password Input 或 Textarea (mono) | 按认证方式显示其一 |
| 分组 | Select（可输入新建） | 可空 |

底部按钮：`[测试连接]` (variant=outline) + `[保存]` (variant=default)。
测试连接：按钮进入 loading，成功变 success 文案"连接成功，Docker 已就绪"，失败显示 destructive 错误原因。
保存后密码 / 私钥立即加密入库，界面不回显明文（编辑时显示占位"已加密保存，留空则不修改"）。

### 3.3 状态

- 加载：表格 Skeleton。空态：EmptyState"还没有主机" + [添加主机]。
- 删除：AlertDialog 二次确认，文案说明只删除本地配置，不影响 VPS。

## 4. 主机详情页

### 4.1 布局

```
内容区
|
|-- 页头: 面包屑(主机 / web-1)  右侧: [编辑] [打开容器管理]
|
|-- Tabs: [资源监控] [基本信息]
|
|-- Tab: 资源监控
|   4 个指标卡 (grid-cols-2 xl:grid-cols-4 gap-4):
|   +------------+ +------------+ +------------+ +------------+
|   | CPU        | | 内存       | | 磁盘       | | 网络       |
|   | 42%        | | 2.1/3.7G   | | 38%        | | ↑1.2MB/s   |
|   | ▓▓▓░░      | | ▓▓░░░      | | ▓▓░░░      | | ↓300KB/s   |
|   +------------+ +------------+ +------------+ +------------+
|   指标卡下方: 简易趋势图 (Card, 近 10 分钟折线, P2)
|   下方: 该主机运行的容器速览 Table (名称/镜像/状态/CPU/内存), 行点击跳容器页
|
|-- Tab: 基本信息
|   Card 两列: 地址/端口/用户/认证方式/分组/系统信息(OS/内核)/Docker 版本/Agent 无
```

### 4.2 状态与刷新

- 监控数据每 5s 轮询（SSH 拉取）；连接断开时指标卡显示 destructive"连接已断开" + [重连]。
- CPU / 内存 > 80% 数值文字转 warning 色，> 90% 转 destructive 色。
