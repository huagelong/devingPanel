# P4 发布执行 / 发布历史 设计文档

> 需求映射：B-2/B-4 构建、T-1/T-2/T-3/T-4 分发、D-2/D-4/D-5/D-6 部署、健康检查、历史与回滚、D-7 历史清理、M-2/M-3/M-4/M-5 多机滚动发布

## 1. 页面目的

承载核心流程：选择项目与目标主机 -> 一键"构建、推送、部署"；实时展示全流程进度；支持失败处理与回滚。

## 2. 入口

- 侧边栏"发布"；项目列表/详情的 [发布] 按钮；Dashboard [去发布]。

---

## 3. 发布执行页

### 3.1 布局

```
内容区
|
|-- 页头: "发布"
|
|-- ① 发布配置条 (Card, 一行 flex)
|   项目 [Select]   版本 tag [Input, 预填规则生成值]   目标: "已选 3 台" [更改]
|   并行度 [Select: 1(默认) / 2 / 3]
|   右侧: [开始发布] (variant=default, 发布中变为 destructive [终止])
|
|-- ② 发布进度总览 (Card)
|   总体步骤条 Stepper: 构建 -> 推送 -> 部署 -> 完成
|   当前步骤 info 色, 已完成 success 色, 失败 destructive 色
|
|-- ③ 各主机进度 Table (Card 包裹)
|  列: 顺序 | 主机 | 状态 Badge | 阶段 | 进度 | 耗时 | 操作
|      1    web-1  [部署中]info  等待健康检查   --     32s    --
|      2    web-2  [等待]muted    --             --     --     --
|      3    web-3  [等待]muted    --             --     --     --
|  推送中: 进度列显示 Progress(百分比)
|  失败行: 操作列 [查看原因] [跳过此台继续] [终止]
|
|-- ④ 构建日志 (Card, Collapsible, 默认展开至发布完成自动折叠)
|   等宽文本区, 深浅色跟随主题, 自动滚动到底部, [复制日志]
```

### 3.2 状态机

单台主机状态：`等待 -> 传输中 -> 部署中 -> 健康检查中 -> 成功 | 失败`。
状态色：等待 = muted，传输/部署 = info，健康检查中 = warning，成功 = success，失败 = destructive。

| 规则 | 行为 |
|------|------|
| 逐台执行 | 第 N 台"成功"后才进入第 N+1 台（M-2） |
| 构建失败 | 全部主机保持"等待"，日志区 destructive 提示失败原因，无主机被部署 |
| 失败默认 | 暂停队列：后续主机保持"等待"，弹 Toast + 失败行出现 [跳过此台继续] [终止] |
| 终止 | 确认后停止队列；已部署完成的主机不回滚，页头出现"本次发布未完成，可一键回滚"提示条 |
| 健康检查 | 部署后轮询容器状态 / 健康端点，超时（默认 120s）判失败 |

### 3.3 发布完成

顶部显示结果条：全部成功 success 背景（success 10% 透明度）"发布成功，耗时 1m24s"；部分失败 destructive 背景"2/3 成功，web-3 失败"。

## 4. 发布历史页（发布页 Tabs: 执行 / 历史）

```
Card Table
列: 时间 | 项目 | 版本 tag(mono) | 目标主机 | 结果 Badge | 耗时 | 操作
操作: [详情] [回滚]
|-- 详情: Sheet 右滑 (sm:max-w-2xl): 每台主机各阶段耗时、失败原因、审计信息
|-- 回滚: AlertDialog 确认, 文案 "将各目标主机切回上一成功版本 vX.Y.Z"
```

回滚规则：仅当上一成功版本的镜像仍在远端保留期内可回滚；超期显示 muted 说明"历史镜像已清理，无法回滚"（D-6/D-7）。

## 5. 状态

- 加载：配置条 Skeleton。无项目：EmptyState"先创建项目" + [新建项目]。
- 发布进行中切换页面：侧边栏"发布"项显示 info 色小圆点，顶部栏全局进度条（h-0.5, info 色）。
