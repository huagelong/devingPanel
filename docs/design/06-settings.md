# P6 设置 设计文档

> 需求映射：D-6/D-7 保留与清理策略、SEC-1/SEC-3 凭据加密与审计日志、T-2 镜像仓库（可选）、BK-1/BK-2/BK-3/BK-4 加密配置备份与恢复、国际化、主题切换

## 1. 页面目的

集中管理全局策略：发布保留策略、外观、数据与安全选项。

## 2. 入口

- 侧边栏"设置"。

## 3. 设置子页面（2026-10-25 修订）

每个设置分组为独立子页面，不再将所有卡片纵向堆叠在一个页面。侧边栏“设置”默认进入发布保留策略；子页面有独立 hash 地址，支持刷新直达及浏览器前进/后退。

| 分类 | 地址 | 页面内容 |
|------|------|----------|
| 发布保留策略 | `#/settings/retention` | 每项目/每主机保留数 1 / 2 / 3（默认）/ 5 / 10 / 自定义（>=1）；N=1 警告；自动清理开关及说明；立即清理入口。最近/下次自动检查时间由正式客户端显示，原型不执行定时清理 |
| 外观 | `#/settings/appearance` | 浅色 / 深色 / 跟随系统；语言 Select：简体中文 / English；与顶部主题按钮同步 |
| 镜像仓库 | `#/settings/registry` | Registry 地址、用户名、令牌、测试登录；未配置时 SSH 直连；凭据安全说明 |
| 备份与恢复 | `#/settings/backup` | 设置/更改/清除加密密码；本地备份 / S3 备份 Tabs；导入导出及加密流程，详见第 5 节 |
| 告警（P2） | `#/settings/alerts` | CPU / 内存 / 磁盘阈值及持续时长；P2 上线前隐藏分类 |
| 本地环境 | `#/settings/environment` | Docker 路径和检测、SQLite 路径与打开文件夹、主机数据采集间隔 |
| 安全 | `#/settings/security` | 本机锁屏密码、无操作间隔、手动锁屏 |

桌面（宽度 >=1024px）在内容区使用 184px 分类导航 + 单一内容卡片，保留全局 App Shell 与主题：

```
顶部面包屑：设置 > 当前分类
页头：设置
+------------------+---------------------------------------+
| 发布保留策略      | 当前分类 Card                          |
| 外观             | 只渲染本分类的表单与操作                |
| 镜像仓库          |                                       |
| 备份与恢复        |                                       |
| 告警（P2）        |                                       |
| 本地环境          |                                       |
| 安全             |                                       |
+------------------+---------------------------------------+
```

窄屏改为“设置分类”Select，下面显示当前子页面，避免第二层侧栏挤占内容；表格仍在卡片内横向滚动。

- 选中分类高亮，面包屑和浏览器标题体现当前分类；每次只渲染一个分组，其他分组的表单不留在隐藏 DOM 中。
- 非秘密配置和会话内加密密码在子页面切换后保留；明文凭据输入不跨页保留。刷新仍按原型会话规则重置，主题与语言偏好除外。
- 未知分类、未启用阶段的告警地址回到默认子页面；P2 切回 P0/P1 时不会继续显示告警表单。
- 离开备份子页面使未完成的读取/加解密结果失效，不能在其他设置子页弹出过期预览。
- 使用前进/后退切换子页时，关闭上一页的弹窗和侧栏，丢弃其中未提交的输入，避免旧操作覆盖当前页面。

## 4. 交互与状态

- 所有设置项即改即存，无需整页保存按钮；保存成功 Toast。
- 主机数据采集间隔控制桌面客户端在线期间从主机采集数据并写入 SQLite 的周期，默认 60 秒；可选 10 / 30 / 60 / 300 秒或自定义 10–3600 秒整数。选择预设后立即生效；自定义值通过输入校验后生效。它不控制页面从 SQLite 读取的间隔，也不改变保存、发布和容器操作后的即时刷新。原型仅保留当前会话的设置值，不实际采集主机数据或写入 SQLite；配置备份包含该非秘密设置。
- 告警阈值和持续时长在当前会话导航后保留；自定义保留数改成 1 与预设 1 使用同一警告逻辑。
- 主题设置与顶部栏主题切换按钮联动（同一份数据）。
- 语言默认简体中文，提供简体中文与 English 两个选项，即选即生效；更新页面标题、`html lang` 和无障碍标签。本机语言偏好保存在 localStorage，刷新保留；不支持的存储值回到中文。
- 切换语言不清空配置、不改变发布状态，不改写项目名/主机名/路径/输入值或日志正文。语言是本机显示偏好，不加入或受配置备份覆盖，跨语言备份恢复保持当前界面语言。
- [测试登录] 成功显示 success 文案"登录成功"；失败显示 destructive 原因。
- 桌面客户端在 `#/settings/registry` 填写 HTTPS Registry 域名（可含端口）、用户名和令牌；留空令牌只在地址与用户名不变时保留已有凭据。保存后可开启“发布使用镜像仓库”，默认关闭。开关启用时，所有构建镜像名须以该地址开头；发布页显示当前传输方式。正在使用 Registry 的未结束发布/批次期间不可修改或删除配置，也不可切换方式。SQLite 保存地址、用户名、启用状态、随机凭据引用及任务/批次传输方式；令牌写入系统凭据管理器，旧引用进入待清理队列。
- Registry 模式仍保留本机归档供回滚；单主机逐镜像推送，多主机共享构建按架构推送一次，目标主机拉取各自平台 tag。批次传输方式持久化，直传任务继续使用 save/SFTP/load。远端拉取前校验可信 SSH、Docker daemon 与架构；拉取后核对镜像 ID，禁止覆盖已有远端 tag。登录与拉取在权限 700 的临时 Docker 配置目录中完成，令牌经 SSH 标准输入传递，命令输出和发布日志不包含令牌。正常退出由远端 shell 清理；下次 Registry 拉取前清理超过 24 小时、无未结束任务引用的遗留目录。连接失败时提示可能残留并建议轮换令牌。
- 批次共享镜像推送中断/超时可能已写入部分 tag；批次标为待核实，禁止自动终止或重试。历史页允许用户独立核对 Registry tag 后二次确认结束该批次；此操作只更新本机批次状态，不清理远端 tag。远端拉取取消或超时会关闭 SSH 会话并尝试删除、验证临时认证目录；无法确认时保留待核实任务并提示轮换令牌。
- Registry 凭据只保存在系统凭据管理器；混合架构发布为每种平台推送带架构后缀的独立 tag，VPS 按自身架构拉取。远端拉取通过 SSH 使用权限 700 的临时 Docker 认证目录（文件权限 600）；正常完成、失败或可捕获的中断时立即清理。客户端崩溃时无法保证立刻清理：下次连接该主机前核对正在执行的任务，仅删除本应用遗留且已过期、无任务引用的临时认证目录；无法连接时明确提示凭据可能残留并建议撤销/轮换令牌。不得把明文凭据写进发布日志或长期 Docker 配置。
- 客户端运行时每日检查一次待清理版本；未运行期间不会自动清理，重启/重连后检查到期主机。客户端不安装 VPS 定时任务；无法连接时记录待处理，连接恢复后再试。"立即清理"是额外入口，不替代定期检查。
- 清理仅按该项目/主机的已完成发布历史挑选受托管镜像，并排除当前运行、其他容器仍引用及保留数内的版本；N=1 时只保护当前版本，不承诺回滚。逐个删除准确 tag，不执行 `docker system prune`。如镜像有多个 tag/被其他项目引用，跳过镜像删除并说明原因。版本退出保留期时，同步删除 VPS 上该版本的部署目录（Compose 与 `.env`）；镜像删除被跳过不影响目录清理，目录删除失败时重试并提示。本地历史快照在对应镜像与远端目录处理完成后才释放，不能因同一镜像仍被其他 tag 引用就无限期保留旧敏感值。
- [立即清理] 先展示将清理的各主机版本、受保护/跳过项与预估空间，确认后逐台执行；完成后 Toast 汇总成功数、失败数和实际释放空间，失败主机可重试。

桌面客户端设计：SQLite 保存全局保留数、自动清理开关、最近检查时间及各历史任务清理状态。默认保留 3 个版本，自动清理默认关闭；客户端每分钟检查是否已达到每日检查时间。设置页显示最近/下次自动检查时间，手动清理先预览候选、受保护与跳过数量，再二次确认。当前预览仅给出已记录的本机归档大小，不提供未经远端核实的镜像可释放空间估算。执行时逐任务取得项目发布锁并重新确认资格；远端操作核对主机与 Docker 身份、镜像和容器引用，删除准确 tag 与部署目录后才释放本机材料。远端未修改前的失败约 15 分钟后自动重试；清理中断或远端结果不确定时记录待核对，自动检查不会盲目重试，用户可从预览中确认后重试。此段描述桌面客户端；WebUI 原型保持独立。

## 5. 配置备份与恢复

放在“本地环境”之前，复用 Card、Tabs、Table 和 Dialog：

```
Card: 备份与恢复
|-- 加密密码: [设置/更改密码] [清除密码]，显示本次会话是否已设置
|-- Tabs: [本地备份] [S3 备份]
|-- 本地: 范围说明 + 主机/项目数量 + [导出配置] [选择文件导入]
|-- S3: Endpoint / Region / Bucket / Prefix / Path-style
|       Access Key ID / Secret Access Key (不回显、不纳入备份)
|       [测试连接] [创建备份]
|       记录: 时间 | Bucket / 对象路径 | 大小 | 状态 | [下载][预览恢复][删除]
|-- 通用: 敏感信息排除说明；不包含 VPS 业务数据、镜像、卷和回滚材料
```

- 备份范围为客户端主机、项目和非秘密设置，不是 VPS 数据备份。不导出 SSH 密码/私钥、Registry/S3 凭据、环境变量值和构建参数值；构建参数仅保留键名。也不包括镜像、容器卷、发布历史或回滚快照。
- `devingpanel.yaml` 是项目目录内的外部文件，不作为本机配置备份的正文；备份只保留项目路径等索引信息。恢复后必须重新读取并校验文件及目标绑定，不能从备份里的旧单服务字段还原 YAML 多构建配置或直接开放发布。
- 所有本地导出和 S3 演示快照必须先加密。创建前设置加密密码并重复输入确认，至少 8 个字符（最多 1024），建议使用较长且唯一的口令。密码仅用于本次页面会话，不写入 SQLite、localStorage、sessionStorage、日志或备份文件；可主动清除，刷新后失效。
- 使用浏览器 Web Crypto 的 AES-256-GCM（128-bit 认证标签）；通过 PBKDF2-SHA-256、600000 次迭代和每份独立的 16-byte 随机盐派生密钥，每份使用独立的 12-byte 随机 nonce。加密头的格式、版本、时间、算法、KDF 参数及 nonce 纳入认证数据。JSON 外层仅包含这些加密元数据与 Base64 密文，配置正文全部加密。
- 本地导出前仍展示数量、时间及排除范围；确认后加密再下载。S3 演示记录保存同一加密封装，不保留配置明文快照；下载时保持原密文。
- 导入/恢复先验证加密封装，再要求输入该备份的密码；密码错误、密文或认证头被修改时拒绝恢复，不展示配置预览、不修改当前数据。解密成功后再校验内部配置结构，之后才允许预览及确认覆盖。解密密码不自动作为新备份密码保存。
- 更改密码仅影响之后创建的备份，不重新加密旧文件；旧备份仍需原密码。明确提示“忘记密码无法恢复”。不支持旧版明文 JSON 直接导入，不做明文兼容或加密不可用时的降级；不支持 Web Crypto 时提示使用 HTTPS / localhost。
- 导入只接受支持的格式版本；校验结构、ID 唯一性、项目主机引用和分组关系。损坏、未知版本、未知/敏感字段、超出大小上限（原型 5 MB）均拒绝，不能部分应用。
- 预览展示来源、主机/项目数及覆盖范围；必须主动勾选覆盖确认后才能导入。导入整体替换配置，不做隐式合并。当前发布历史与容器缓存清空，不把配置恢复当作部署恢复。
- 发布运行中、暂停或待核实时禁止导入/恢复，确认提交时再次检查；允许导出配置。
- 文件读取或加密/解密期间离开当前操作、关闭弹窗或开启其他弹窗时，废弃未完成结果，不能抢占后续操作、触发过期下载或覆盖未保存表单。
- 恢复后所有主机为离线且须重新确认指纹；项目为待确认状态，要求核对路径、补齐构建参数、重配环境变量及凭据。备份不恢复远端状态或主机信任，不影响真实 VPS。
- S3 配置支持 HTTPS Endpoint、Region、Bucket、Prefix 与 Path-style；连接错误与备份结果明确反馈。正式桌面版的 S3 凭据仍须保存在系统凭据管理器，不能写入 SQLite、备份文件或日志。S3 通信由客户端经 HTTPS 发起，不新增 VPS 端服务。
- **当前 HTML 实现边界**：密码加密、解密及本地文件下载/读取真实可用，恢复仅影响当前浏览器会话；S3 不发网络请求、不保存云端凭据，仅模拟配置检查与备份记录。按钮和记录须显式标注“演示/仅本地模拟”；刷新后模拟记录消失，不声称云端备份成功。S3 下载和恢复复用同一份加密格式与密码流程。

桌面客户端设计：SQLite 保存 S3 的非秘密配置与随机凭据引用，Secret Key 存系统凭据管理器；S3 通过 HTTPS 直接测试、上传、列出、下载和删除同格式密文。备份密码只保留在当前桌面窗口内存中，离开备份子页使异步预览失效。导出含主机、项目、环境变量及构建参数的键名、保留策略；不含任何凭据、变量或参数的值。恢复事务再次检查发布、回滚及批次任务，替换本机配置并清空本机历史；旧密钥材料和归档进入可重试清理队列。恢复项目进入待复核状态，用户核对本地路径、参数、变量和主机凭据后需在项目页确认，发布入口才重新开放。桌面端不恢复主机指纹，也不修改 VPS。

## 6. 本机锁屏与自动锁定（2026-10-25）

安全子页的单一 Card 显示“本机锁屏”设置：

```
安全 / 本机锁屏
|-- 状态: 未启用 / 已启用
|-- 未启用: [新锁屏密码] [确认密码] [无操作自动锁屏间隔] [启用锁屏]
|-- 已启用: [无操作自动锁屏间隔] [保存间隔] [修改锁屏密码]
|            [立即锁屏] [关闭锁屏]
|-- 说明: 仅保护本机界面，不替代 OS 登录、磁盘加密或服务器认证
```

- 间隔指用户**无操作多久后锁定**，不是免密解锁期限。可选 1/5/15/30/60 分钟及自定义 1–1440 分钟，默认 5 分钟；鼠标、键盘、触摸与滚动可视为操作，后台停留超时后恢复焦点仍须锁定。
- 启用时密码最少 8 字符、最多 1024 字符，两次输入一致。当前 HTML 原型仅在 localStorage 保存随机 16-byte 盐及 PBKDF2-SHA-256（600000 次）派生的验证值，不保存明文密码或可恢复口令；不把锁屏密码加入配置备份或日志。修改密码、间隔与停用时先验证当前密码。密码丢失无法在原型内找回。
- 手动锁屏入口位于顶栏。锁定时关闭弹窗、清理未提交的敏感输入和会话备份加密密码；使用全屏模态界面遮蔽背景，关闭 Escape 解锁路径。错误密码只给出错误提示，不解除锁定；解锁后保留原页面及非秘密配置。刷新/重新打开时若配置存在，则启动即显示锁屏。
- 多个同源浏览器标签页共享锁屏设置；另一个标签页启用或变更后，已有标签页也须锁定。原型的浏览器界面锁不能抵御操作系统账户持有者、浏览器开发工具或离线修改本地存储；不声称保护 VPS 凭据、进程内存或硬盘数据。
- 页面语言为英语时，设置与锁屏界面一并翻译；在锁屏界面仍可切换语言，不改变验证值或解锁状态。

桌面客户端设计：SQLite 保存独立锁屏盐、PBKDF2-SHA-256 验证值与无操作间隔。启动即锁定；手动和超时锁定遮蔽主界面、关闭弹窗并清除会话备份密码及未提交的敏感表单。锁屏密码派生在后台线程执行，多个运行实例每 5 秒同步一次锁屏配置。主机编辑器可保存加密 OpenSSH 私钥的口令；私钥与口令作为同一份敏感材料保存，超过 MyGo Secrets 单项上限时按 `docs/technical-architecture.md` 使用本机加密文件和凭据管理器中的密钥，替换或删除引用沿用现有待清理队列。审计日志写入应用数据目录 `audit/events.jsonl`，仅记录时间、固定操作名、对象类型/ID、阶段和成功/失败，不写入错误正文或秘密值。审计文件写入失败时会在进程诊断输出中报告，不回滚已经完成的操作。锁屏只保护当前桌面客户端窗口，不替代系统登录与磁盘加密。
