# P5 容器管理 设计文档

> 需求映射：C-1/C-2/C-3/C-4/C-5 容器列表、操作、日志、镜像、磁盘清理、S-2/SEC-2 仅经 SSH 且不在 VPS 装 agent

## 1. 页面目的

以 SSH 只读 + 操作命令的方式，提供轻量 Docker 管理能力，替代 VPS 上的常驻管理面板。

## 2. 入口

- 侧边栏"容器"；主机详情 [打开容器管理]。

## 3. 布局

```
内容区
|
|-- 页头: "容器"  右侧: [清理磁盘] (variant=outline)
|-- 共用工具条: 左侧主机切换 Select，右侧 Tabs [容器] [镜像]
|-- 工具条下方: 刷新间隔及演示说明
|
|-- Tab 容器:
|  资源表格（直接展示，表头轻底色）
|  列: 状态 | 名称(mono) | 镜像(mono) | 端口 | CPU | 内存 | 操作
|       ●Up 3d  web-1  myapp:v1.4.2  0.0.0.0:80->8080  2%  120MB  [日志][...]
|  操作列 DropdownMenu: 启动 / 停止 / 重启 / 删除(destructive)
|  点击名称或日志操作 -> 日志 Sheet
|
|-- Tab 镜像:
|  Table: 仓库名:tag(mono) | 大小 | 创建时间 | 未使用标记 | 操作[删除]
|  顶部次操作: [清理悬空镜像] (variant=ghost)
```

## 4. 容器日志 Sheet

右侧滑出 Sheet `sm:max-w-2xl`：

```
SheetHeader: web-1 (mono)  [跟随] Switch  [停止] [重启]
主体: 等宽日志区 (bg-muted, h 全高, 自动滚动到底部)
      跟随开启时新日志自动追加; 手动上滚时暂停跟随, 底部出现 [回到底部]
底部: 条数上限提示 "仅显示最近 1000 行 (docker logs)"
```

## 5. 清理磁盘 Dialog

1. 第一步：点击 [清理磁盘] 后执行预检（`docker system df`），Dialog 展示全局可回收空间估值：悬空镜像 / 停止容器 / 未使用网络 / 构建缓存；提示估值不等于本次 `docker system prune` 的实际释放空间，且可能包含其他项目的资源。
2. 第二步：AlertDialog 列明操作范围（将删除其他项目的停止容器、未使用网络及缓存等）并确认"这是全局 Docker 清理，可能影响其他项目"；默认不选中卷清理，不把本操作当作发布历史镜像清理。
   `docker system prune` 也可能删除未被容器引用但仍作为回滚材料的无标签镜像，确认文案必须明确指出此风险；不能宣称该入口保护发布历史版本。
3. 完成后 Toast 显示实际释放空间。

## 6. 状态与确认

- 加载：表格 Skeleton；主机 SSH 不可达：Card 内错误态 + [重试]。
- 无主机或空数据时显示“当前没有容器或镜像”。
- 停止 / 删除 / 重启：AlertDialog 二次确认（删除为 destructive 按钮）；执行中行内 loading，完成 Toast。
- 容器列表的数据来源与刷新间隔见 `docs/technical-architecture.md`；正在操作的行禁用操作按钮防止重复提交。
- 镜像列表中当前运行或受发布保留策略保护的镜像禁用删除，显示保护原因；删除镜像也需二次确认。
- [清理悬空镜像] 不得直接执行主机全局 `docker image prune` 并声称保护发布版本：无标签但仍需回滚的镜像可能被删除。接入发布历史保护或精确筛选前禁用此入口并说明原因。
- WebUI 原型的镜像页将“清理悬空镜像”置为禁用并显示原因；当前运行和保留版本的删除按钮也禁用。容器、镜像、日志和释放空间均为演示数据，不代表已操作 VPS。

## 操作确认与窄窗口原型

停止、重启和删除的确认正文同时列出主机名、容器名及中断服务提示，确认按钮使用实际动作名称。列表和日志 Sheet 共用这条确认路径。

容器、镜像列表在 1023px 及以下按对象显示字段名，长镜像名换行，操作区占整行。原有删除保护和演示边界不变。


## 对象上下文与列表密度

工具条将主机选择与视图切换靠左紧邻放在同一行，右侧显示刷新间隔及演示说明，窄窗口允许换行。容器和镜像表保留完整字段，使用 1px 边框容器收口，在表格容器不足 1080px 时提前转为字段分组。日志侧栏在标题下同时显示主机名和镜像引用，避免切换主机后混淆日志对象；仍使用原生模态 Sheet，宽窗口保留可见的背景列表，关闭后返回原列表。停止、重启和删除的确认规则不变。
