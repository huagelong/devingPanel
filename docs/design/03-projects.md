# P3 项目列表 / 项目详情 设计文档

> 需求映射：B-1 项目关联、B-3 构建参数、D-1 多 compose 文件、D-3 环境变量（SEC-4 写入远端 .env 权限 600）、M-1 绑定多主机

## 1. 页面目的

管理"项目"：本地代码目录、Dockerfile、compose 文件、构建参数、环境变量与目标主机的绑定关系。项目是发布的最小单元。

## 2. 入口

- 侧边栏"项目"；发布页选择项目。

---

## 3. 项目列表页

### 3.1 布局

```
内容区
|
|-- 页头: "项目" + [新建项目] (variant=default)
|
|-- Table (Card 包裹)
|  列: 项目名 | 本地路径(mono, 截断) | 绑定主机数 | 最近发布 | 状态 | 操作
|       myapp   D:\code\myapp          3        2h前 v1.4.2  就绪  [发布][...]
|  操作列: [发布] 主按钮 + DropdownMenu(详情/编辑/删除)
```

### 3.2 新建项目 Dialog（sm:max-w-2xl）

| 字段 | 控件 | 说明 |
|------|------|------|
| 项目名 | Input | 必填 |
| 本地代码目录 | Input + [浏览] | 必填，系统目录选择器 |
| Dockerfile 路径 | Input | 相对代码目录，默认 `Dockerfile` |

创建后跳转项目详情页完善其余配置；详情未配置完成时列表"状态"列显示 warning Badge"待完善"。

---

## 4. 项目详情页

### 4.1 布局

```
内容区
|
|-- 页头: 面包屑(项目 / myapp)  右侧: [发布] (variant=default)
|
|-- Tabs: [构建配置] [Compose] [环境变量] [目标主机] [发布历史]
```

### 4.2 Tab: 构建配置

Card 表单：

| 字段 | 控件 |
|------|------|
| 镜像名 | Input (mono)，默认 = 项目名小写 |
| Tag 规则 | Input (mono)，支持 `{date}` `{git-sha}` 占位，默认 `{date}-{git-sha}` |
| 目标平台 | Select: linux/amd64（默认）/ linux/arm64 |
| Build args | Key-Value 编辑列表（Add row） |

底部 [保存]；保存后 Toast 反馈。

### 4.3 Tab: Compose

```
Card
|-- 说明行: "支持多个 compose 文件，按顺序合并（后者覆盖前者）"
|-- 文件列表 (可排序，每行):
|    1. docker-compose.yml          [本地路径, mono] [移除]
|    2. docker-compose.prod.yml     [+ 添加文件]
|-- [+] 添加 compose 文件 (系统文件选择器, 可多选)
|-- 预览区: 折叠面板 Collapsible "查看合并预览 (docker compose config)"
|    内部: 等宽只读文本块 (bg-muted rounded-lg p-4)
```

交互：调整顺序用上移/下移按钮；文件不存在于本地时行内 warning 提示"文件不存在"。

### 4.4 Tab: 环境变量

```
Card
|-- 分组 Select: [按主机] [项目通用]
|-- Key-Value 编辑列表: KEY | VALUE(可切换明文/掩码) | [删除行]
|-- [+] 添加变量      [保存]
|-- 提示条 (muted): "部署时写入远端 .env（权限 600），不纳入镜像"
```

- VALUE 默认掩码显示（`text-sm` 圆点），点击眼睛图标临时明文。
- 标记为敏感的变量在表格中始终掩码，仅创建时可查看。

### 4.5 Tab: 目标主机

```
Card
|-- Table: 勾选 | 状态点 | 主机名 | 地址 | 分组
|-- 数据源: 主机列表；项目绑定的主机勾选
|-- 底部说明 (muted): "发布时按列表顺序逐台部署，健康检查通过后进入下一台"
```

### 4.6 Tab: 发布历史

该项目维度的发布记录 Table：时间 | 版本 tag | 目标主机数 | 结果 | 耗时 | 操作([详情])。
点击详情跳转发布页对应记录。最近 20 条，分页 `Previous / Next`。
