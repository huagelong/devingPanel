# devingPanel HTML 原型

按 `docs/design/00-overview.md` 至 `06-settings.md` 实现的浏览器交互原型。默认展示 P1 页面，使用固定演示主机与项目。不是桌面客户端或远端管理服务。

## 打开

只读预览可直接打开 `index.html`。要导入、重读或保存 `devingpanel.yaml`，请通过下面的 localhost 服务在支持 File System Access API 的 Chrome/Edge 中打开，并在浏览器提示时选择项目目录。目录授权仅在当前页面会话有效。

也可以启动仅监听本机的预览服务：

```sh
cd webui
npm start
```

访问 `http://127.0.0.1:4173`。`npm start` 仅需要 Node.js，不需要先安装 npm 依赖。

- P2：增加趋势图、告警配置。
- 加载、空、错误及正常页面状态。
- 健康成功、部署失败、SSH 断开待核实、单机无 HEALTHCHECK 情景。

- `devingpanel.yaml` 项目的目录导入、多个构建服务、Compose 顺序、目标绑定编辑、重读和实际写回项目文件。SSH、Docker、发布和容器数据仍是演示。

## 原型边界

- 不运行 Docker、SSH、Compose，不读写 SQLite 或操作系统凭据管理器；“连接”终端输入不会执行命令。主机地址使用文档保留地址段。
- 发布进度、资源值、指纹、日志、清理空间与回滚均为演示，界面明确标注。远端实际状态无法由此原型验证。
- 主机/项目/非秘密设置在当前页面会话中有效，刷新重置；主题与语言偏好写入浏览器 localStorage。
- YAML 页面保存前核对项目文件、Dockerfile、Compose 服务镜像变量和外部修改；校验通过后写入所选项目目录。目录句柄不会持久化，刷新后需重新授权。浏览器文件写入由所选浏览器实现提交；桌面客户端仍负责发布前重读与远端预检。
- 密码、私钥、敏感变量和 Registry 令牌不持久化；请勿输入真实凭据。环境变量“保存”只验证格式并清空输入，不假装已完成安全存储。
- 设置页“备份与恢复”须先设置加密密码并二次确认（8–1024 字符）。本地备份使用真实的密码加密 JSON 下载和文件读取，文件最多 5 MB。导入先输入原密码，解密校验成功后预览并勾选覆盖确认；只影响本次浏览器会话。
- S3 表单、配置检查和备份记录为明确标注的演示，不访问云端。模拟记录可下载或预览恢复，刷新后消失。S3 凭据不保存、不导出，测试后清空。
- 配置备份只含主机/项目/非秘密设置；排除凭据、环境变量值及所有构建参数值（仅保留键名），不含 VPS 镜像/卷、发布历史与回滚材料。所有配置正文（包括地址与路径）均使用 AES-256-GCM 加密；S3 演示记录同样只存加密封装。
- 采用 Web Crypto：PBKDF2-SHA-256 / 600000 次迭代、每份 16-byte 随机盐、12-byte 随机 nonce、128-bit GCM 标签；格式与算法元数据纳入认证。加密密码只留在当前页面会话内，不写入配置、浏览器存储或备份文件；刷新或主动清除后需重新设置。
- 更改密码只影响新备份，旧文件仍需旧密码；忘记密码无法恢复。旧版明文 JSON 不再直接接受导入；浏览器不支持安全加密时拒绝创建，不降级到明文。推荐通过 `npm start` 的 localhost 预览使用。
- 导入拒绝未知版本、未知字段、错误类型、重复 ID 和悬空引用。运行中/暂停/待核实发布不能恢复配置；恢复会清空现有演示发布历史和容器缓存，将主机重置为离线未信任、项目标记为待确认。需要重新补齐参数、核对配置和确认指纹。
- 目录选择/打开系统文件夹需桌面端接口，当前给出明确提示；Compose 路径由演示输入维护，不解析真实文件。`{git-sha}` 使用标注的示例值，而非读取 Git。
- 原型校验已知数据中的平台匹配、Compose 首文件位置、保留键、发布标识冲突和可回滚版本；不声称完成 Docker 配置语义校验。
- 资源和日志不是后台真实轮询，不发系统通知；退出页面无远端任务，关闭浏览器即终止演示。

## 代码结构

- `index.html`：App Shell 与原生 Dialog / Sheet 容器。
- `styles.css`：文档 HSL Token、共用组件、桌面和窄屏布局。
- `app.js`：统一图标、表单/表格/卡片渲染函数、六组页面、演示状态及交互。
- `i18n.js` / `i18n-en.js`：中文/英文界面翻译与本机语言偏好，无第三方运行时依赖。
- `backup.js`：共享的备份格式、白名单导出与导入校验，不依赖 UI。
- `backup-ui.js`：本地 JSON 文件交互、恢复预览和 S3 演示记录；复用原有 UI 组件。
- `screen-lock.js`：本机锁屏、密码验证、空闲计时与安全子页表单。
- `serve.cjs`：无第三方依赖的本机静态预览服务，仅公开指定的页面资源。
- `tests/ui.spec.cjs`：Playwright 浏览器回归。
- `tests/backup.spec.cjs`：配置备份往返、数据排除、非法文件、覆盖确认、操作互斥及 S3 页面回归。
- `tests/backup-encryption.spec.cjs`：密码设置/清除、独立 Node crypto 解密验证、随机性、错误密码、篡改、旧密码、明文拒绝与异步取消回归。

## 设置子页面

设置不再是长页面：桌面采用分类导航与单个内容面板，窄屏使用分类选择器。

- `#/settings/retention`：发布保留策略（默认）
- `#/settings/appearance`：外观
- `#/settings/registry`：镜像仓库
- `#/settings/backup`：备份与恢复（保留本地/S3 Tabs 和加密密码流程）
- `#/settings/alerts`：告警（P2 预览）
- `#/settings/environment`：本地环境（Docker/SQLite 路径、主机数据采集间隔演示设置）
- `#/settings/security`：安全

支持 URL 直达、刷新与浏览器前进/后退；切换分类保留会话内配置，但不保留未提交的凭据输入。新增 `tests/settings-pages.spec.cjs` 检查子页面隔离、导航、移动布局与阶段限制。

主机数据采集间隔默认 60 秒，可选 10 / 30 / 60 / 300 秒或自定义 10–3600 秒整数；设置在本次页面会话中生效，并包含在加密配置备份中。原型不执行主机采集或 SQLite 写入。配置备份正文格式为版本 2，旧版正文不直接导入。

## 中文与英语

设置 → 外观 → 语言可切换 `简体中文` / `English`。默认中文，选择保存在 `devingpanel-language`，刷新后保留；语言偏好仅属于本机界面，不加入加密备份，也不会被导入覆盖。

中文源文案作为词典键，英文集中维护于 `i18n-en.js`。`I18n.t` 用于明确的 UI 文案，`I18n.html` 只处理模板静态部分，`I18n.msg` 保留动态参数供显示时翻译；用户数据不经过翻译。新增界面文案需同步英文词典，不要翻译业务状态值、选项值、路径或原始日志。

`tests/i18n.spec.cjs` 检查语言持久化、各页面与弹窗英文覆盖、窄屏溢出、数据/日志保护、发布过程中切换及跨语言加密恢复；没有依赖在线翻译服务。

## 本机锁屏

设置 → 安全可启用锁屏密码，配置无操作锁定间隔（1、5、15、30、60 或自定义 1–1440 分钟，默认 5 分钟）；顶栏锁图标可立即锁屏。修改密码、间隔或关闭锁屏均需验证当前密码。启用后刷新页面或重新打开也需要密码解锁；已打开的其他同源标签页会同步锁定。

密码不以明文保存；浏览器 localStorage 中仅有独立随机盐、PBKDF2-SHA-256（600000 次）验证值及间隔。忘记密码无法通过原型找回。锁定会清除未提交的敏感输入和当前会话备份加密密码。锁屏仅防止临时离开时他人在界面继续操作，不能抵御 OS 账户持有者、DevTools 或篡改浏览器存储，**不替代系统登录、磁盘加密和 VPS 认证**。配置备份不包含锁屏密码/验证值。

`tests/screen-lock.spec.cjs` 验证手动与空闲锁定、活动重置计时、重启锁定、密码变更和停用再认证、敏感输入清除、跨标签同步、中文/英语与移动版，以及加密/存储不可用时不明文降级。
